# HTTP Request & Response Analysis

## Website
http://localhost/CyberSecurity-Assignments/Assignment-1/php/login.php

### Request

- Method: POST
- Protocol: HTTP/1.1
- Host: localhost
- Content-Type: application/x-www-form-urlencoded

### Response

- Status Code: 200 OK
- Server: Apache
- Content-Type: text/html

### Observation

The browser sent the username and password to the PHP application using the POST method. Apache processed the request and returned a successful response containing the login result page.
